📸 Instagram Clone

Um clone da interface do Instagram desenvolvido como projeto de estudo de desenvolvimento Front-End.
O objetivo do projeto é replicar o layout e a experiência de usuário (UI/UX) da tela inicial e das telas de formulário de login/cadastro da rede social.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias fundamentais do desenvolvimento web:

* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização, layout flexível (Flexbox), posicionamento e estilização de formulários.
* **Reset CSS:** Padronização de estilos entre diferentes navegadores.

---

## 📁 Estrutura do Projeto

A organização dos arquivos no repositório está disposta da seguinte forma:

```text
Insta_clone-main/
├── index.html     # Página principal (Feed / Interface principal)
├── form.html      # Página de autenticação (Login / Cadastro)
├── reset.css     # Arquivo de reset de estilos padrão do navegador
├── style.css     # Estilos globais e da página principal
└── form.css      # Estilos específicos para os formulários
```

---

## 🛠️ Como Executar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Brenosilva23/Insta_clone-main.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd Insta_clone-main
   ```

3. **Abra no navegador:**
   Basta dar dois cliques no arquivo `index.html` ou utilizar uma extensão como o **Live Server** no VS Code.
